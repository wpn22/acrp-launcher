# حماية ACRP Launcher ووضع Offline

## ما تم تنفيذه

- اسم الباك يبقى `AcRp` كما تتطلب الإضافات الحالية.
- قبل التشغيل يقوم اللانشر بفحص ملفات الباك حسب بصماتها في ملف التوزيع، وأي ملف معدل أو ناقص يتم تنزيل النسخة الصحيحة منه.
- تمت إضافة خيار `Offline` في شاشة الدخول لاستخدام اسم لاعب بدون حساب Microsoft.
- تم إصلاح تشغيل مكتبات `MCEF / JCEF` بإضافة مسارات Java الداخلية المطلوبة عند إقلاع اللعبة.

## مهم قبل فتح Offline للعامة

وضع `Offline` لا يثبت ملكية اسم اللاعب عن طريق Microsoft. أي شخص قد يحاول دخول السيرفر باسم لاعب آخر إذا لم تكن هناك حماية داخل السيرفر.

الحماية المطلوبة في السيرفر:

1. تشغيل نظام تسجيل ودخول للاعبين Offline داخل السيرفر.
2. منع الحركة والأوامر والمخزون قبل نجاح تسجيل الدخول.
3. ربط حسابات الإدارة بأسماء محمية وكلمات مرور قوية، وعدم إعطاء الصلاحيات بالاسم فقط.
4. الإبقاء على نسخة احتياطية دورية للعالم وملفات الصلاحيات.

## معلومات أحتاجها لإكمال الحماية

- عنوان السيرفر والمنفذ.
- نوع برنامج السيرفر الذي ستستخدمه مع Forge 1.12.2.
- هل تريد السماح بحساب Microsoft وOffline معا، أم Offline فقط؟
- أسماء الإدارة التي يجب حمايتها من الانتحال.

بعد توفير هذه البيانات يمكن إعداد حماية الدخول المناسبة للسيرفر وربط تجربة اللانشر بها.
