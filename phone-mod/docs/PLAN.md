# خطة ACRP Phone — النسخة الثانية

> **الهدف:** جوال بمستوى **LB Phone** (FiveM) لكن داخل ماينكرافت 1.12.2،
> بشكل **iOS**، مع نظام شرائح، وواجهة برمجية تسمح لمودات السيرفر الأخرى
> (اقتصاد، شخصيات، تجارة) بالاندماج فيه.

---

## 1. المراجع وكيف نستخدم كل واحد

| المرجع | نأخذ منه | لا نأخذ منه |
|---|---|---|
| **SPhone** (Minecraft 1.12.2) | الإثبات التقني: جوال يشتغل فعلاً على 1.12.2 — شكل الـAPI، ربط المكالمات بـSimple Voice Chat، فكرة أنواع التطبيقات (SYSTEM/DEFAULT/DOWNLOADABLE) | أي كود أو أصول (نكتب من الصفر) |
| **LB Phone** (FiveM) | **المرجع الأساسي للمنتج**: كتالوج التطبيقات، تدفق الإعداد الأولي، عمق الـAPI، فلسفة "الجوال غرض له هوية" | مستحيل نسخ كل شيء — نرتّبه بطبقات |
| **iOS** | لغة التصميم: شاشة القفل، رمز المرور، الشبكة الأيقونية، الـDock، مركز التحكم، الإشعارات، الحركات النابضة | — |

### ملاحظة مهمة عن الشرائح
**LB Phone نفسه ما فيه نظام شرائح** — الشرائح إضافات خارجية
(NRG SimCard، mps-lbphone-simcards). بما إنك طلبت الشريحة إجبارية،
راح نبنيها **جزء أساسي من النواة** — وهذي نقطة نتفوق فيها على المرجع.

## 3. تدفق التشغيل الأول (الإعداد)

مبني على تسلسل LB Phone/iOS الفعلي:

```
تشغيل  →  اختيار اللغة (العربية / English)
       →  المظهر (فاتح / داكن)
       →  ⚠️ فحص الشريحة
       →  رمز المرور (يمكن تخطيه)
       →  اسم الملف الشخصي
       →  الشاشة الرئيسية
```

**بدون شريحة:** الجوال يشتغل لكن يظهر **«لا توجد شريحة»** في شريط الحالة،
ولا يعمل إلا: الإعدادات، الكاميرا، الساعة، الحاسبة، وطوارئ فقط.
لا رسائل ولا مكالمات ولا أي تطبيق يحتاج شبكة.

## 4. نظام الشرائح (نواة أساسية)

```
ItemSimCard  →  NBT: number, ownerUUID, carrier, registered
ItemPhone    →  NBT: simSlot, deviceId, wallpaper, installedApps, passcode
```

| القاعدة | الأثر في الرول بلاي |
|---|---|
| البيانات (رسائل، جهات اتصال، حسابات) مربوطة بـ**رقم الشريحة** وليس بالجوال | تبديل الشريحة = تبديل الهوية |
| بيانات الجهاز (صور، إعدادات) مربوطة بـ**الجوال نفسه** | سرقة جوال = تحصل صوره — نفس فلسفة LB Phone |
| **شريحة مسجّلة** = مربوطة بالشخصية، الشرطة تتعقبها | تحقيقات |
| **شريحة غير مسجّلة (burner)** = مجهولة | جرائم منظمة |
| نزع الشريحة = فقدان الخدمة فوراً | |

## 5. واجهة الاندماج مع مودات السيرفر 🔑

بما إن عندك مود اقتصاد ومود شخصيات ومود تجارة، هذي **ترتفع لتصير مرحلة
مبكرة** بدل ما تكون في الآخر. الأسلوب: **مزوّدات (providers)** بحيث
الجوال ما يعتمد على أي مود مباشرة.

```java
public interface EconomyProvider {
    long    getBalance(UUID player, String account);
    boolean withdraw(UUID player, String account, long amount, String reason);
    boolean deposit (UUID player, String account, long amount, String reason);
    List<Transaction> history(UUID player, String account, int limit);
}

public interface CharacterProvider {          // مود الشخصيات
    CharacterInfo get(UUID player);           // الاسم، الهوية، الوظيفة
}

public interface TradeProvider {              // مود التجارة
    String  createListing(UUID seller, ItemStack item, long price);
    boolean buy(UUID buyer, String listingId);
    List<Listing> search(String query, int page);
}
```

**التسجيل:**
```java
PhoneIntegrations.registerEconomy(new SarosMoneyAdapter());
```

**قواعد التصميم:**
- كل مزوّد **اختياري** — لو ما تسجّل أحد، التطبيق المرتبط به يختفي من الجوال
  بدل ما ينهار.
- الاكتشاف بـ`Loader.isModLoaded("...")` + محوّلات (adapters) جاهزة لمودات
  سيرفرك.
- مود ثالث يقدر **يشحن تطبيق جواله بنفسه** — مود التجارة يسجّل تطبيق
  «السوق» بدون ما نعدّل الجوال.

**واجهة التطبيقات (على نمط LB Phone custom apps):**
```java
@PhoneApp(id = "market", name = "السوق", icon = "...", type = DOWNLOADABLE)
class MarketApp extends PhoneApplication {
    void onInstall(); void onOpen(); void onClose(); void onDelete();
}
PhoneAPI.sendNotification(player, "market", "بيعة جديدة", "...", actions);
```

## 6. كتالوج التطبيقات — بطبقات

مرجعنا كتالوج LB Phone الكامل (26 وحدة)، مرتّب حسب الجدوى في ماينكرافت:

### الطبقة 1 — الأساس (لا غنى عنها)
الهاتف/الاتصال · الرسائل · جهات الاتصال · الإعدادات · متجر التطبيقات ·
الساعة (منبه/مؤقت/ستوب واتش) · الحاسبة · الملاحظات · الطقس

### الطبقة 2 — اقتصاد الرول بلاي (تعتمد على مودات سيرفرك)
المحفظة/البنك ← *مود الاقتصاد* · السوق ← *مود التجارة* ·
الصفحات الصفراء (دليل الأعمال) · البريد · الوظائف/الخدمات ← *مود الشخصيات*

### الطبقة 3 — التواصل الاجتماعي
InstaPic (صور) · Birdy (تغريدات) · DarkChat (غرف مشفّرة) · Spark (تعارف)

### الطبقة 4 — متقدمة/ثقيلة
الكاميرا + الصور (التقاط من framebuffer) · الخرائط والعلامات ·
الكراج ← *DynamX موجود بالباك* · المنزل ← *SecurityCraft موجود بالباك* ·
العملات الرقمية · الموسيقى · المذكرات الصوتية ·
المتصفح ← *mcef + webdisplays موجودين بالباك*

> الطبقة 4 ممكنة لأن الباك أصلاً فيه المودات المساعدة — لكنها آخر ما ننفّذ.

## 8. أسئلة مفتوحة تؤثر على التنفيذ

1. **أسماء المودات بالضبط** — الاقتصاد `SarosMoneyModWPN`؟ والشخصيات
   والتجارة؟ وهل هي **من صنعك** (نضيف hooks مباشرة) أو خارجية
   (نحتاج adapters/reflection)؟
2. **الصوت** — الباك فيه `voicechat-forge-1.12.2-2.5.31` **و**
   `VelocityVoice-AcRp.jar`. أيهما المستخدم فعلياً للمكالمات؟
3. **`acphone-1.0.jar` الحالي** — نستبدله أو يشتغلون جنب بعض؟
   (لو جنب بعض لازم نتأكد من عدم تصادم modid والأوامر.)
