# ACRPJobs — نظام الوظائف التفاعلي لسيرفر Adventure City

بلق إن Bukkit لسيرفر **Minecraft 1.12.2 / Mohist (أو Magma)** يعطي سيرفر الرول بلاي نظام وظائف
كامل: دوام، مهام بأهداف على الخريطة، رواتب دورية، رتب وترقيات، طلبات تاكسي من اللاعبين،
واقتصاد AC واحد مع سجل تدقيق لكل حركة مالية.

> **الفكرة الأساسية:** الوظائف **بيانات** مو كود. أي وظيفة جديدة = ملف YAML في مجلد `jobs/`
> بدون أي برمجة.

---

## البناء

يحتاج **JDK 8** و **Maven**:

```bash
cd server/acrp-jobs
mvn clean package
```

الناتج: `target/ACRPJobs-1.0.0.jar`

أو حمّله جاهزاً من **GitHub Actions ➜ Build Jobs Plugin ➜ Artifacts** بعد أي push.

## التركيب

1. حط الجار في مجلد `plugins/` في سيرفر Mohist 1.12.2.
2. شغّل السيرفر — تنشأ الملفات تلقائياً في `plugins/ACRPJobs/`:
   - `config.yml` — كل أرقام النظام
   - `messages_ar.yml` — كل النصوص العربية
   - `jobs/` — سبع وظائف جاهزة (توصيل، تاكسي، شاحنات، نظافة، بستنة، كهرباء، بناء)
   - `routes.yml` — مسارات سكان المدينة (تُرسم داخل اللعبة)
   - `spots.yml` — نقاط الزبالة والأوساخ والزرع والإنارة (تُحدَّد داخل اللعبة)
   - `data.db` — قاعدة بيانات SQLite (تلقائية، بدون إعداد)
3. حدد المناطق داخل اللعبة (الخطوة الوحيدة الإلزامية) 👇

## إعداد المناطق (ضروري قبل التشغيل)

الوظائف تشير إلى **أسماء مناطق** مو إحداثيات، عشان تشتغل على أي خريطة. قف في المكان واكتب:

```
/jobsadmin zone check          ← يعرض لك بالضبط وش ناقص
```

المناطق المطلوبة للوظائف السبع:

| المنطقة | الوظيفة | الأمر (قف بالمكان أول) |
|---|---|---|
| `delivery_depot` | التوصيل — مقر الدوام والاستلام | `/jobsadmin zone set delivery_depot 6` |
| مجموعة `customers` | التوصيل — بيوت العملاء (٣ فأكثر) | `/jobsadmin zone set house1 5 customers` |
| `taxi_stand` | التاكسي — مقر الدوام | `/jobsadmin zone set taxi_stand 8` |
| مجموعة `taxi_stands` | التاكسي — مواقف الزبائن | `/jobsadmin zone set stand1 5 taxi_stands` |
| مجموعة `city_points` | التاكسي — وجهات داخل المدينة | `/jobsadmin zone set mall 6 city_points` |
| `truck_depot` | الشاحنات — المستودع الرئيسي | `/jobsadmin zone set truck_depot 8` |
| مجموعة `truck_stops` | الشاحنات — محطات التفريغ (٢ فأكثر) | `/jobsadmin zone set stop1 6 truck_stops` |
| `cleaner_depot` | النظافة — مقر الدوام | `/jobsadmin zone set cleaner_depot 6` |
| `city_dump` | النظافة — المكب | `/jobsadmin zone set city_dump 8` |
| `garden_depot` | البستنة — المشتل ومقر الدوام | `/jobsadmin zone set garden_depot 6` |
| `power_depot` | الكهرباء — المستودع ومقر الدوام | `/jobsadmin zone set power_depot 6` |
| `build_depot` | البناء — المستودع ومقر الدوام | `/jobsadmin zone set build_depot 8` |
| مجموعة `build_sites` | البناء — مواقع البناء (٢ فأكثر) | `/jobsadmin zone set site1 6 build_sites` |

> كل ما زادت المناطق في المجموعة، صارت المهام أقل تكراراً. النظام يختار عشوائياً ويتجنب تكرار نفس
> النقطة مرتين ورا بعض.

| الأمر | الوظيفة |
|---|---|

## ربط المتجر (مهم)

خلي المتجر (Tebex / تسليم يدوي) يسلّم عبر أمر الكونسول:

```
ac give %player% 100000 store
```

كذا رصيد المتجر ورصيد الوظائف **نفس المحفظة**، وكل عملية تنكتب في جدول `acrp_transactions`
بسببها — تقدر ترجع لأي عملية بعد شهور.

## التوازن الاقتصادي

الأرقام الافتراضية مبنية على سعر متجرك (**100,000 AC = 10$**) بهدف: **الباقة ≈ ٢٠ ساعة لعب**.

| البند | الافتراضي | مكانه |
|---|---|---|
| هدف الدخل | ~5,000 AC/ساعة | مجموع الأرقام تحت |
| عقد توصيل | 200–350 AC | `jobs/delivery.yml` |
| رحلة تاكسي | 150 AC + 3 AC/بلوك | `jobs/taxi.yml` |
| رحلة شاحنة | 900–1,400 AC | `jobs/trucker.yml` |
| جولة نظافة | 240–320 AC | `jobs/cleaner.yml` |
| جولة سقي | 260–340 AC | `jobs/gardener.yml` |
| صيانة إنارة | 320–420 AC | `jobs/electrician.yml` |
| حمولة بناء | 350–450 AC | `jobs/builder.yml` |
| راتب الدوام | 100–340 AC / 30 دقيقة | `grades` في كل ملف وظيفة |
| ضريبة الرواتب | 10% | `payroll.taxPercent` |
| ضريبة التحويل | 5% | `config.yml` |
| الحد اليومي | 60,000 AC | `antiAbuse.dailyEarningCap` |

**لا تلغِ الضرائب.** هي مصارف العملة الوحيدة حالياً، وبدونها الاقتصاد يتضخم خلال أسابيع.

## الحماية من الاستغلال

- **تبريد** لكل مهمة، و**حد يومي** لكل لاعب — والتبريد يصمد مع إعادة الدخول (relog ما يصفّره).
- **كشف الخمول**: الواقف بدون حركة ما يستلم راتب أصلاً (`payroll.afkSeconds`).
- **فحص منطقية الحركة**: أي انتقال أسرع من `maxBlocksPerSecond` لمسافة أطول من 100 بلوك يوقف الدفع
  ويسجل تحذير في الكونسول.
- **حد أدنى لزمن المهمة** (`minContractSeconds`) — المهمة اللي تخلص بسرعة غير منطقية ما تُدفع.
- **سجل تدقيق كامل**: `acrp_transactions` (كل حركة AC) و `acrp_contract_log` (كل مهمة).

## قاعدة البيانات

SQLite افتراضياً. للـ MySQL غيّر `storage.type: mysql` واملأ البيانات ثم **أعد تشغيل السيرفر**
(تغيير قاعدة البيانات ما ينفع مع `reload`).

كل القراءة والكتابة تصير على **ثريد منفصل** — ما فيه أي استعلام على الـ main thread، وهذا مهم مع
مودات ثقيلة مثل ModularWarfare و DynamX.

## إضافة وظيفة جديدة (بدون كود)

انسخ أي ملف من `jobs/` وعدّله. أنواع الخطوات المتاحة:

| النوع | الوصف | الخصائص |
|---|---|---|
| `GOTO_ZONE` | وصول لمنطقة | `zone` أو `zoneGroup`, `radius` |
| `GOTO_PLAYER` | التوجه للاعب صاحب الطلب | `radius` |
| `PICKUP_ITEM` | استلام غرض | `item`, `amount`, `itemName` |
| `DELIVER_ITEM` | تسليم الغرض في منطقة | `zone`/`zoneGroup`, `amount` |
| `WAIT_TIMER` | انتظار بمكان محدد | `seconds` |
| `CONFIRM` | تأكيد يدوي بـ `/jobs confirm` | `target: PLAYER`, `radius`, `markRideStart` |
| `CLEAR_SPOTS` | نظّف عدد من نقاط العمل | `pool`, `amount` |

> الخطوة اللي ما تحدد منطقة **ترث** منطقة الخطوة اللي قبلها — كذا تقدر تسوي «توجه ثم انتظر ثم سلّم»
> في نفس المكان.

بعد أي تعديل: `/jobsadmin reload`

## شخصيات المدينة (NPCs) والحوارات الذكية

الـ NPCs يشتغلون **بدون ذكاء اصطناعي أصلاً**: كل شخصية في `npcs.yml` لها ردود مكتوبة. الذكاء
طبقة إضافية اختيارية فوقهم.

### الشخصيات الجاهزة (٥)

| المعرّف | الاسم | مين هو | يقدر يسوي |
|---|---|---|---|
| `job_officer` | أبو سعد | موظف مركز التوظيف | يعرض **الوظائف الثلاث** + يوجّه للمناطق |
| `dispatcher` | أم خالد | غرفة عمليات التاكسي | تعرض **وظيفة التاكسي ومهامها** |
| `guide` | دليل المدينة | مرشد سياحي | **يوجّه للمناطق فقط** — ما يوظّف |
| `baqala_owner` | أبو فهد | صاحب بقالة (زبون توصيل) | كلام + يوجّه لمستودع التوصيل |
| `citizen` | مواطن | ساكن يمشي في الشارع | **كلام فقط** — مخصص للمسارات |

الترتيب مقصود: كل ما نزلت في الجدول قلّت صلاحيات الشخصية. **`citizen` هو اللي تربطه بالمسارات**
لأنه أرخص شخصية (CHAT فقط)، وبيكون موجود بأعداد كبيرة في الشوارع:

```
/jobsadmin route set main_street persona citizen
```

### الربط مع NPC داخل اللعبة

يشتغل مع **Citizens** و **CustomNPCs** معاً — الربط بالاسم الظاهر، بدون أي اعتماد برمجي على
أي منهما، ويصمد بعد إعادة تشغيل السيرفر:

```
/jobsadmin npc link job_officer     ← قف قدام الـ NPC وانظر له
/jobsadmin npc list                 ← كل الشخصيات وحالة ربطها
/talk job_officer                   ← للتجربة بدون NPC أصلاً
```

بعد الربط: **نقرة يمين على الشخصية** تبدأ المحادثة، وكلامك في الشات يروح لها بدل الشات العام.
تنتهي المحادثة بـ `/talk end` أو بالابتعاد أو بعد ٩٠ ثانية صمت.

### تفعيل الذكاء الاصطناعي

1. شغّل الجسر: `server/acrp-ai-bridge` (اقرأ README حقه)
2. في `config.yml`: `ai.enabled: true` وحط نفس التوكن

**القاعدة الذهبية:** الذكاء يكتب **الكلمات فقط**. الإجراءات محصورة في قائمة ثابتة
(`CHAT` / `OFFER_JOB` / `OFFER_CONTRACT` / `DIRECT_TO_ZONE` / `DECLINE`)، والبلق إن يتحقق منها
**مرة ثانية** مقابل حالة السيرفر الفعلية: لو عرض وظيفة غير موجودة أو غير مسموحة لهذي الشخصية،
يتحول الرد لكلام عادي بدون أي إجراء. **مستحيل NPC يعد لاعب بشي ما يقدر النظام يعطيه.**

ولو الجسر توقف أو خلصت ميزانيته أو تأخر الرد → الشخصية ترد بجملة مكتوبة من `npcs.yml`.
**ما فيه مسار يكسر اللعبة.**

## التدريب الميداني — الشرح يجيك من مدني ماشي في الشارع

ما فيه لاعب يقرأ كتيّب. عشان كذا **كل وظيفة يشرحها لك موظف حقيقي يمشي في المدينة**، على الأرض،
وأنت تشتغل.

### كيف يشتغل

1. تتوظّف من `/jobs` ➜ تجيك رسالة: **«روح دوّر على أبو ماجد»**
2. تلقاه **يمشي جولته في الحي** (هو أصلاً واحد من سكان المسارات)
3. **نقرة يمين عليه** ➜ يوقف، يلتفت لك، ويشرح لك الدرس الأول
4. تسوي اللي قاله ➜ **الدرس الثاني يجيك وأنت تشتغل**، بصوته
5. تخلص الدروس ➜ يتخرّج معك ويصير بعدها شخصية عادية تتكلم معها

### الدرس ما يعدّي بالضغط — يعدّي بالشغل

كل درس ينتظر **الفعل الحقيقي** اللي شرحه:

| المُشغّل | الدرس يعدّي لما |
|---|---|
| `DUTY_START` | تسجّل دوامك فعلاً |
| `CONTRACT_START` | تستلم مهمة فعلاً |
| `SPOT_CLEARED` | تنظّف أول نقطة فعلاً |
| `STEP_DONE` | تخلص خطوة من المهمة |
| `CONTRACT_DONE` | تخلص المهمة كاملة وتستلم أجرك |
| `TALK` | ترجع تكلّمه (للخاتمة) |

يعني **مستحيل** لاعب يضغط Enter عشر مرات ويطلع «متدرّب» وهو ما سوى شي.

**الدرس الأول لازم وجهاً لوجه** — ما يجيك بالراديو. لازم تمشي وتلقاه. بعدها هو يتابعك عن بُعد
عشان ما نخليك تقطع المدينة رايح جاي بين كل جملة.

### المشرفون السبعة

| الوظيفة | المشرف | شخصيته |
|---|---|---|
| النظافة | **أبو ماجد** | مشرف حي من ١٢ سنة، يفتخر بحيّه ويزعل من كيس متروك |
| البستنة | **أم نورة** | تعرف كل شجرة بعمرها، تحذّرك من الماء الزايد |
| الكهرباء | **المهندس سالم** | السلامة قبل كل شي: «العمود المعطّل مو خطر، المتسرّع هو الخطر» |
| البناء | **المقاول أبو تركي** | عملي ومباشر: «أنت ناقل مواد، مو بنّاء» |
| التوصيل | **أبو ريان** | يقيس السائق بشيئين: الوقت وأدبه مع الزبون |
| التاكسي | **أبو بدر** | أقدم سائق في المدينة، مرح لكن جاد: «الراكب أمانة» |
| الشاحنات | **أبو مشعل** | هادئ: «الشاحنة الثقيلة ما تنفع فيها العجلة» |

### تشغيلهم (خطوة وحدة)

خلّ المشرف **يمشي** بين الناس العاديين — واحد فقط، مو ثلاثة نسخ منه:

```
/jobsadmin route set north_walk leadPersona cleaner_foreman
```

`leadPersona` تنطبق على **أول بوت في المسار فقط**، والباقي يظلون `citizen` عاديين. والمشرف
**له أولوية في الظهور** على المواطنين المجهولين، عشان لاعب قيل له «دوّر على أبو ماجد» يلقاه فعلاً.

> بديل: لو تبيه واقف في مقر العمل بدل ما يمشي — `/jobsadmin npc link cleaner_foreman` وهو
> واقف قدامك. الاثنين يشتغلون بنفس الكود.

### أوامر

| الأمر | الوظيفة |
|---|---|
| `/jobs learn` | أعد سماع الدرس الحالي بدون ما تدوّر على المشرف |

### تعديل الشرح أو إضافة وظيفة جديدة

كل الكلام في ملف الوظيفة نفسه — **بدون كود**:

```yaml
training:
  trainer: cleaner_foreman
  intro: "&7روح دوّر على &aأبو ماجد&7."
  lessons:
    - trigger: DUTY_START
      hint: "روح لمقر النظافة واكتب /duty"
      text:
        - "أهلاً يا ولدي. أنا أبو ماجد، مشرف نظافة الحي الشمالي."
        - "أول شي: ما فيه شغل بدون تسجيل دوام."
```

تقدمك محفوظ في قاعدة البيانات لكل وظيفة على حدة — تخرج وترجع وتكمّل من نفس الدرس.

## ضمان عدم التخريب

**هذا البلق إن ما يغيّر ولا بلوك واحد في خريطتك.** ولا وظيفة من السبع تكسر أو تحط أو تحرّك أي شي:

| الوظيفة | وش تلمس فعلياً |
|---|---|
| النظافة | كيان مؤقت (كيس) + جزيئات + عنصر في حقيبتك |
| البستنة | جزيئات فقط |
| الكهرباء | جزيئات فقط |
| البناء / التوصيل / الشاحنات / التاكسي | عناصر في الحقيبة فقط |

- **عصا التحديد تلغي كسر البلوكات** وأنت ماسكها — حتى في وضع الكرييتف
- **المضخة ما تعبّي ماء** ولا تنحط في العالم
- **أدوات العمل ما تنرمي**
- **الاستثناء الوحيد الممكن** هو إضاءة عمود الإنارة، ومقفول **من مكانين** لازم تفتحهم معاً:

```yaml
world:
  allowBlockChanges: false     # المفتاح الرئيسي في config.yml
```
```
/jobsadmin spot set street_lamps swapBlock true    # وللمجموعة نفسها
```

وحتى في الدروس نفسها، كل مشرف يكرر القاعدة بلسانه: **«إحنا ننظّف، ما نخرّب»** ·
**«نصلّح — ما نكسر ولا نفكّ»** · **«أنت ناقل مواد، مو بنّاء»**.

## الوظائف المدنية ونقاط العمل (Work Spots)

الوظائف الأولى كلها من نوع «روح لمنطقة». الوظائف المدنية مختلفة: فيها **أشياء موجودة فعلاً في
الشارع** تشوفها وتتفاعل معها — أكياس زبالة، بقع وساخة، زرع ذابل، أعمدة إنارة معطّلة.

### كيف يشتغل الدوران

تحدد **مجموعة نقاط** (مثلاً ٢٠ مكان)، وتقول كم وحدة منها فيها شغل في نفس الوقت (مثلاً ٩):

```
/jobsadmin spot new city_trash TRASH   ← ياخذك لوضع التحديد ويعطيك العصا
  نقرة يمين على بلوك  →  نقطة جديدة
  نقرة يسار على بلوك  →  تراجع
/jobsadmin spot done                   ← يعرض النقاط ويسأل [نعم] / [لا]
/jobsadmin spot set city_trash activeCount 9
```

- أول ما ينظّف العامل نقطة، ينقص العدد لـ ٨ **ويظل ٨** طول مدة `respawnMinutes`.
- بعدها ترجع نقطة جديدة في **مكان ثاني**، فيصير ٩.
- **النقطة اللي ما أحد نظّفها ما تتحرك أبداً** — تظل مكانها لين ينظفها أحد.

> النتيجة: الحي اللي تهمله **يتراكم فيه الوسخ فعلاً**، والحي اللي تنظفه **يبان نظيف عشر دقائق**.
> وهذا مجاناً بدون أي إعداد إضافي.

### الأنواع الأربعة

| النوع | شكله في العالم | كيف يُنظَّف | يكلّف كيان؟ |
|---|---|---|---|
| `TRASH` | كيس زبالة على الأرض | نقرة يمين عليه | نعم — كيان صغير واحد |
| `DIRT` | بقعة دخان رمادية | **مضخة الماء** | **لا — جزيئات فقط** |
| `PLANT` | زرع ذابل يتساقط غباره | **مضخة الماء** | **لا — جزيئات فقط** |
| `LAMP` | دخان وشرر على العمود | نقرة يمين | **لا — جزيئات فقط** |

**ثلاثة من الأربعة بدون أي كيان** — يعني تقدر تغطي المدينة كلها بشغل بدون ما تحس بشي على TPS.
الزبالة وحدها لها سقف في `config.yml`:

```yaml
spots:
  maxActiveEntities: 20     # أكياس الزبالة الظاهرة في نفس الوقت على السيرفر كله
```

والكيس ما يوجد إلا إذا فيه لاعب قريب، ويُوسم بـ `acrp_work_spot` في NBT عشان **يُمسح تلقائياً
عند التشغيل** لو صار كراش.

### مضخة الماء

أداة واحدة تشتغل لوظيفتين: **تغسل البقع** و**تسقي الزرع**.

- تجيك تلقائياً أول ما تبدأ الدوام، وتُسحب منك عند إنهائه (`tool: PUMP` في ملف الوظيفة)
- وجّهها على البقعة واضغط **يمين** — الرش يشتغل لحاله ٣ ثواني، ما تحتاج تضغط باستمرار
- يُلغى لو ابتعدت أو غيّرت الأداة
- **ما تنرمي** ولا تقدر تعبّي فيها ماء

### لازم تكون على الدوام

أي لاعب عادي **ما يقدر** ينظّف نقاط المدينة — لو كان يقدر، كان أي واحد يمسح كل الشغل ويخلي
العمال بدون رزق. الشرط: تكون على الدوام في وظيفة.

### الوظائف الأربع

| الوظيفة | وش تسوي | تحتاج نقاط؟ |
|---|---|---|
| **عامل النظافة** | يجمع أكياس زبالة + يغسل بقع ➜ يفرّغ في المكب | `city_trash` (TRASH) · `city_dirt` (DIRT) |
| **البستاني** | يسقي الزرع الذابل بنفس المضخة | `park_plants` (PLANT) |
| **الكهربائي** | يصلح أعمدة الإنارة المعطّلة | `street_lamps` (LAMP) |
| **عامل البناء** | ينقل مواد من المستودع لمواقع البناء | **لا** — مناطق فقط |

المناطق المطلوبة: `cleaner_depot` · `city_dump` · `garden_depot` · `power_depot` ·
`build_depot` + مجموعة `build_sites`.

**اكتب `/jobsadmin zone check`** — يقول لك بالضبط وش ناقص من مناطق **ونقاط**.

### أوامر النقاط

| الأمر | الوظيفة |
|---|---|
| `/jobsadmin spot new <اسم> <النوع>` | ابدأ التحديد (ياخذ العصا) |
| `/jobsadmin spot edit <اسم>` | افتح مجموعة محفوظة للتعديل |
| `/jobsadmin spot add` | أضف موقعك كنقطة |
| `/jobsadmin spot undo` | تراجع عن آخر نقطة |
| `/jobsadmin spot done` | إنهاء + سؤال نعم/لا |
| `/jobsadmin spot set <اسم> activeCount 9` | كم نقطة فيها شغل في نفس الوقت |
| `/jobsadmin spot set <اسم> respawnMinutes 10` | كم دقيقة قبل ما ترجع المنظّفة |
| `/jobsadmin spot show <اسم>` | اعرض النقاط — **برتقالي = فيها شغل، أخضر = مستريحة** |
| `/jobsadmin spot list` / `del <اسم>` | إدارة المجموعات |

### وظيفة جديدة تستخدم النقاط (بدون كود)

نوع خطوة واحد يكفي:

```yaml
- type: CLEAR_SPOTS
  pool: city_trash
  amount: 8
  title: "اجمع ٨ أكياس زبالة من الشوارع"
```

### ملاحظة صريحة عن الكهربائي

عمود الإنارة في 1.12.2 مشكلته إن `REDSTONE_LAMP_ON` يرجع ينطفي مع أول تحديث بلوك جنبه.
عشان كذا **الجزيئات (دخان وشرر) هي الإشارة المضمونة**، وتبديل البلوك نفسه خيار اختياري
**معطّل افتراضياً**:

```
/jobsadmin spot set street_lamps swapBlock true
```

جرّبه على سيرفرك أول قبل ما تعتمد عليه.

### اختبار سريع

حدد ٢٠ نقطة زبالة ➜ `activeCount 9` ➜ تأكد إن ٩ ظهروا ➜ ابدأ الدوام (لازم تجيك المضخة) ➜
`/jobs` وابدأ جولة ➜ اجمع ٨ أكياس ➜ فرّغ في المكب ➜ **انتظر ١٠ دقائق وتأكد إن اللي نظّفته
انتقل لمكان ثاني واللي ما نظّفته باقي مكانه** ➜ اغسل بقعة بالمضخة ➜ ابتعد ٦٠ بلوك (الأكياس
تختفي) ➜ ارجع ➜ أعد تشغيل السيرفر (ما يبقى ولا كيس).

## سكان المدينة المتحركون (Routes)

بدل ما الـ NPCs يوقفون في مكان واحد، **ترسم المسار بنفسك** والبوتات ترسبن عشوائياً عليه وتمشي عليه.

### ليش هذا أخف من أي نظام ثاني

Spigot 1.12.2 **ما فيه واجهة برمجية للـ pathfinding** أصلاً. بما إنك رسمت الطريق بيدك فهو
**مضمون سالك**، فما نحتاج حسابات مسار — نحسب موضع على خط مكسور ونحرّك البوت بـ teleport. البوت
يُستدعى بـ `setAI(false)` يعني **صفر حمل ذكاء فانيلا**. النتيجة: بوت على مسار مرسوم **أرخص من
قروي عادي واقف في مدينتك**.

### الرسم (٤ خطوات)

```
/jobsadmin route new main_street     ← يعطيك عصا الرسم
  نقرة يمين على بلوك  →  زاوية جديدة (عمود لهب يظهر عليها)
  نقرة يسار على بلوك  →  تراجع عن آخر زاوية
/jobsadmin route done                ← يرسم الخط كامل ويسألك
```

يجيك في الشات: **عدد الزوايا · الطول · وقت الدورة** + زرين تضغط عليهم مباشرة:

```
هل المسار مناسب؟   [ ✔ نعم ]   [ ✘ لا ]
```

- **نعم** → يُحفظ في `routes.yml` والبوتات تبدأ تمشي فوراً.
- **لا** → ترجع للتعديل و**الزوايا ما تروح** — عدّل واضغط `done` مرة ثانية.

المرئيات تظهر **لك أنت فقط**: الزوايا **عمود لهب برتقالي**، والخط **نقاط بيضاء كل نصف بلوك** —
عشان تشوف الفرق بين نقطة الانعطاف والمسار الفعلي. والعصا **تلغي كسر البلوكات** وأنت ماسكها،
فالنقرة اليسار ما تخرب بناءك.

### الحد الأقصى: ٥ بوتات في نفس الوقت

في `config.yml`:

```yaml
routes:
  maxActiveWalkers: 5
```

هذا **سقف على السيرفر كله**، مو لكل مسار. لو عندك ١٠ مسارات ومجموع سكانها ٣٠ بوت، يوجد منهم
**٥ فقط ككيانات** — دائماً **الأقرب للاعبين** — والباقي يتحرك «افتراضياً» بأرقام في الذاكرة بدون
كيان. لما يتحرك اللاعبون، تنتقل الحصة تلقائياً للمسار اللي عنده لاعبين. يعني الخمسة **دايماً
حيث فيه ناس يشوفونهم**.

### الأوامر

| الأمر | الوظيفة |
|---|---|
| `/jobsadmin route new <اسم>` | ابدأ الرسم (ياخذ العصا) |
| `/jobsadmin route edit <اسم>` | افتح مسار محفوظ للتعديل |
| `/jobsadmin route add` | أضف موقعك كزاوية (مفيد وأنت طاير) |
| `/jobsadmin route undo` | تراجع عن آخر زاوية |
| `/jobsadmin route done` | إنهاء + سؤال نعم/لا |
| `/jobsadmin route confirm yes\|no` | التأكيد كتابةً بدل الزر |
| `/jobsadmin route show <اسم>` | اعرض مسار محفوظ بالجزيئات ٢٠ ثانية |
| `/jobsadmin route set <اسم> <خاصية> <قيمة>` | عدّل خاصية بدون إعادة رسم |
| `/jobsadmin route list` / `del <اسم>` | إدارة المسارات |

### خصائص المسار

| الخاصية | الافتراضي | الوصف |
|---|---|---|
| `mode` | `LOOP` | `LOOP` يلف ويرجع لأول زاوية · `PINGPONG` يمشي ويرجع بالعكس |
| `speed` | `3.2` | بلوك/ثانية (قريبة من سرعة مشي اللاعب) |
| `population` | `3` | كم بوت على هذا المسار (يحده السقف العام) |
| `entity` | `VILLAGER` | **يشتغل بدون أي مود**. غيّره لو ركّبت Citizens |
| `persona` | `""` | فاضي = ديكور صامت · معرّف من `npcs.yml` = **يتكلم** |
| `names` | `مواطن، ساكن المدينة` | اسم عشوائي فوق كل بوت |
| `activationRange` | `48` | ما يوجد ككيان إلا إذا فيه لاعب داخل هذي المسافة |
| `pauseChance` | `0.15` | احتمال وقفة قصيرة عند كل زاوية |

مثال: `/jobsadmin route set main_street persona citizen` ➜ صار كل بوت على هذا المسار
**يتكلم بنظام الحوارات** — ينقر عليه اللاعب، **البوت يقف ويلتفت له**، وبعد نهاية المحادثة
**يكمل مشيه من نفس النقطة**.

> الربط هنا **عن طريق المسار مو عن طريق الاسم**، فتقدر تسمّي بوتاتك أي أسماء وتظل تتكلم.

### التنظيف

كل بوت يُوسم بـ `acrp_route_npc` والوسم **يُحفظ في NBT الكيان**. عند تشغيل السيرفر يُمسح أي كيان
يحمل الوسم — **ينظف بقايا أي كراش سابق تلقائياً**. وأي بوت تُفرَّغ قطعته من الذاكرة يُحذف فوراً،
فما يمكن أبداً يبقى قروي تايه في خريطتك.

### اختبار سريع على سيرفر تجريبي

حدد ٤ زوايا ➜ شوف الخط ➜ `done` ➜ اضغط **لا** (يرجع للتعديل والزوايا موجودة) ➜ عدّل ➜ `done` ➜
**نعم** ➜ البوتات تمشي ➜ ابتعد ٦٠ بلوك (يختفون) ➜ ارجع (يظهرون من نفس مكانهم مو من البداية) ➜
كلّم واحد (يقف ويلتفت لك) ➜ أنهِ المحادثة (يكمل) ➜ أعد تشغيل السيرفر (ما يبقى ولا كيان).

## نظام الطلبات (Dispatch)

`/taxi call` يرسل الطلب لكل سائق **على الدوام وفاضي**. أول سائق يقبل تبدأ عنده المهمة تلقائياً،
والأجرة تُخصم **من محفظة الراكب** (لو ما عنده كفاية، البلدية تغطي الفرق بحد أقصى `basePay`).

الوظيفة تستقبل الطلبات عن طريق `dispatch: taxi` في ملفها + عقد فيه `dispatchOnly: true`.
**نفس الآلية بالضبط بتشغّل ٩١١ للشرطة والإسعاف في المرحلة القادمة** — فقط غيّر اسم القناة.

## الخطوات القادمة

- **P2**: مزيد من الوظائف المدنية (ميكانيكي، صياد، طباخ) + جسر Vault
- **P3**: الشركات والخزائن (محلات لاعبين ورواتب من خزينة الشركة)
- **P4**: واجهة MCEF/HTML (جوال داخل اللعبة) + وظائف غير قانونية

## ملاحظات تقنية

- **نصوص الواجهات (الصناديق)** مكتوبة في الكود؛ **رسائل اللعب** كلها في `messages_ar.yml`.
- `messages_ar.yml` و ملفات الوظائف تُقرأ بترميز **UTF-8 صراحةً** حتى ما تتكسر العربية على
  سيرفرات لغتها الافتراضية غير UTF-8.
- التكامل مع DynamX/CustomNPCs عبر أوامر كونسول في `config.yml` (`integration`) — **معطّل
  افتراضياً** حتى ما ينكسر شي لو تغيرت المودات.
