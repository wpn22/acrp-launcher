# ACRP AI Bridge — جسر حوارات NPC الذكية

خدمة صغيرة تعمل **خارج سيرفر الماين كرافت** وتعطي شخصيات المدينة (NPCs) حوارات ذكية بالعربي.

## ليش خارج السيرفر؟

عشان **صفر ثقل على اللعبة**. سيرفر الماين كرافت ما يتصل بالذكاء الاصطناعي أبداً — يرسل نص لـ
`localhost` ويستلم نص، والاتصال نفسه غير متزامن. حتى لو هذي الخدمة توقفت تماماً، السيرفر يشتغل
عادي و NPCs يردون بحواراتهم المكتوبة مسبقاً.

## المبدأ الأساسي: **الذكاء يتكلم، المحرك يقرر**

الموديل **ما يقرر منطق اللعبة إطلاقاً**. هو يختار من قائمة إجراءات محددة سلفاً، والبلق إن يتحقق
منها مرة ثانية قبل ما ينفذها:

| الإجراء | معناه |
|---|---|
| `CHAT` | كلام عادي بدون أي إجراء |
| `OFFER_JOB` | عرض وظيفة (من قائمة وظائف هذا الـ NPC فقط) |
| `OFFER_CONTRACT` | عرض مهمة محددة |
| `DIRECT_TO_ZONE` | توجيه اللاعب لمنطقة |
| `DECLINE` | رفض مهذب (إساءة أو خروج عن الموضوع) |

**مثال حقيقي من الاختبارات:** لو الموديل رد بـ «وظفتك ضابط شرطة براتب مليون» وهذا الـ NPC ما
يملك وظيفة الشرطة، النظام **يحذف الإجراء تلقائياً** ويحوله لكلام عادي. اللاعب ما يستلم وعد
مستحيل. هذي أكبر مشكلة في NPCs الذكاء الاصطناعي، ومحلولة من التصميم.

## التشغيل

```bash
cd server/acrp-ai-bridge
npm install
cp config.example.json config.json     # عدّل التوكن
export ANTHROPIC_API_KEY=sk-ant-...     # مفتاحك من console.anthropic.com
npm start
```

**بدون مفتاح** الخدمة تشتغل في **وضع المحاكاة** — كل شي يعمل (الحماية، الكاش، الحدود، السجلات)
لكن الردود ثابتة. مفيد للتجربة قبل ما تصرف أي ريال.

```bash
npm test    # 30 اختبار، ما يحتاج مفتاح ولا إنترنت
```

## الحماية

- **يستمع على `127.0.0.1` فقط.** لا تعرّضه للإنترنت أبداً — فيه مفتاحك وسيصير نقطة فوترة مفتوحة.
- **توكن مشترك** بين البلق إن والخدمة (`Authorization: Bearer`)، مقارنة بزمن ثابت.
- **كلام اللاعب معامَل كحديث مو كتعليمات** — والقواعد تمنع تغيير دور الشخصية.
- **كل محادثة تُسجّل** في `logs/dialogue.log` للمراقبة. اللاعبون **بيحاولون** يخلون الـ NPC يقول
  كلام سيء — هذا السجل هو أداتك.

## التحكم بالتكلفة (ثلاث طبقات)

1. **كاش**: نفس السؤال لنفس الـ NPC = نفس الجواب، بدون تكلفة وبدون تأخير. مفتاح الكاش يتجاهل
   اسم اللاعب لكن يراعي وضعه (وظيفته)، والنص العربي يُوحّد (`أبي` = `ابي`) عشان تزيد الإصابات.
2. **حد لكل لاعب**: `playerMessagesPerMinute` (افتراضي ٥).
3. **سقف يومي بالدولار**: `dailyBudgetUsd` (افتراضي $5). لما ينتهي، كل الـ NPCs يرجعون للحوار
   المكتوب تلقائياً — **ما يتوقف شي في اللعبة**.

راقب الصرف: `curl http://127.0.0.1:8787/health`

### الأسعار (لكل مليون توكن)

| الموديل | إدخال | إخراج | ملاحظة |
|---|---|---|---|
| `claude-opus-5` | $5 | $25 | الافتراضي — الأقوى |
| `claude-sonnet-5` | $3 | $15 | متوازن |
| `claude-haiku-4-5` | $1 | $5 | **الأرخص — الأنسب لحوارات NPC الكثيرة** |

الرد الواحد ≈ أقل من عُشر سنت على Haiku. غيّر `model` في `config.json` حسب ميزانيتك.

> **ملاحظة عن الكاش على مستوى الموديل:** قواعد الشخصيات المشتركة تُرسل ككتلة ثابتة أولاً عشان
> تستفيد من الـ prompt caching. الحد الأدنى للتخزين ٥١٢ توكن على Opus 5 و٤٠٩٦ على Haiku 4.5 —
> يعني على Haiku غالباً ما يفعّل الكاش، وهذا مقبول لأن سعره أصلاً منخفض.

## واجهة الـ API

```
POST /dialogue            (يحتاج التوكن)
GET  /health              (إحصائيات وصرف اليوم)
```

**الطلب:**
```json
{
  "npcId": "job_officer",
  "npcName": "أبو سعد",
  "persona": "موظف مركز التوظيف، ودود ومختصر",
  "playerId": "<uuid>",
  "playerName": "WPN",
  "message": "ابي شغل",
  "allowedIntents": ["CHAT", "OFFER_JOB", "DECLINE"],
  "allowedTargets": { "OFFER_JOB": ["delivery", "taxi"] },
  "context": { "الوظيفة": "لا يوجد", "الرصيد": "5,000 AC" },
  "history": [{ "role": "user", "text": "..." }, { "role": "npc", "text": "..." }]
}
```

**الرد:**
```json
{ "ok": true, "reply": "هلا والله...", "intent": "OFFER_JOB", "target": "delivery", "source": "model" }
```

`source` تكون `model` أو `cache` أو `mock`. وأي فشل يرجع `ok: false` مع سبب، والبلق إن يستخدم
الحوار المكتوب — **لا يوجد مسار يكسر اللعبة**.

## التشغيل الدائم (systemd)

```ini
[Unit]
Description=ACRP AI Bridge
After=network.target

[Service]
WorkingDirectory=/opt/acrp-ai-bridge
Environment=ANTHROPIC_API_KEY=sk-ant-...
ExecStart=/usr/bin/node src/server.js
Restart=always
User=acrp

[Install]
WantedBy=multi-user.target
```
