# التجربة على ويندوز — الدليل الكامل

## أول شي: تصحيح مهم

**`C:\Users\wpn\curseforge\minecraft\Instances\test` هذا مجلد لاعب (Client)، مو سيرفر.**

البلق إن ما يشتغل هناك أبداً — البلق إنات تنحط في **سيرفر**، والمودات تنحط في اللاعب.
شيئين مختلفين تماماً:

| | وين | وش ينحط فيه |
|---|---|---|
| **اللاعب (Client)** | `curseforge\...\Instances\test` | **مودات** فقط |
| **السيرفر (Server)** | مجلد منفصل تختاره أنت | **بلق إنات** فقط |

## ثاني شي: كم مود يحتاج نظام الوظائف؟

**ولا واحد.**

فحصنا كل استيراد في الكود: `java` و `org.bukkit` و `net.md_5` (اللي يجي مع السيرفر) وبس.
**صفر مودات.** البوتات قرويين عاديين، الزبالة عنصر ساقط، الأوساخ جزيئات، الحوارات شات.
كله فانيلا.

يعني: **تقدر تجرب كل شي بلاعب ماين كرافت 1.12.2 عادي بدون Forge أصلاً.**

## الطريقة (أ) — الأسرع والموصى بها للتجربة

**بدون أي مود، لا في اللاعب ولا في السيرفر.** تجرب ١٠٠٪ من النظام.

### ١. حمّل المشروع

افتح PowerShell:

```powershell
cd C:\Users\wpn\Desktop
git clone https://github.com/wpn22/acrp-launcher.git
cd acrp-launcher
git checkout claude/minecraft-server-job-system-7cybph
```

> ما عندك git؟ افتح صفحة المستودع في المتصفح ➜ الفرع `claude/minecraft-server-job-system-7cybph`
> ➜ زر **Code** ➜ **Download ZIP** ➜ فك الضغط.

### ٢. ركّب Java 8

ماين كرافت 1.12.2 **ما يشتغل** على Java 17 أو 21. لازم **Java 8** بالذات:

https://adoptium.net/temurin/releases/?version=8 ➜ اختر **Windows x64 JDK 8** ➜ `.msi`

تأكد بعدها:
```powershell
java -version
```
لازم يطلع `1.8.0_...`

### ٣. حمّل جار البلق إن

من **GitHub ➜ Actions ➜ Build Jobs Plugin ➜ آخر تشغيل ➜ Artifacts ➜ ACRPJobs-plugin**

فك الضغط وحط `ACRPJobs-1.0.0.jar` في:
```
acrp-launcher\server\acrp-jobs\target\
```

### ٤. شغّل الإعداد

```powershell
cd server\test-server
.\setup.bat
```

ينزّل السيرفر، يركّب البلق إن، وينسخ **٢٠ منطقة و٨ مسارات و٨٠ نقطة عمل** جاهزة.

### ٥. شغّل السيرفر

```powershell
.\run\start.bat
```

أول ما يخلص التحميل، اكتب في نفس النافذة:
```
op wpn
```

### ٦. ادخل

ماين كرافت **1.12.2** (بدون Forge) ➜ Multiplayer ➜ Direct Connect ➜ `localhost`

### ٧. افحص

```
/jobsadmin test
```

## الطريقة (ب) — لو تبي تجرب مع مودات سيرفرك

هذي **مو ضرورية لتجربة نظام الوظائف**. سوّها فقط لو تبي تتأكد إن النظام ما يتصادم مع
مودات سيرفرك الحقيقي (DynamX، ModularWarfare، CustomNPCs).

### القاعدة الذهبية

**نفس المودات بالضبط لازم تكون في الجهتين** — في مجلد `mods` حق السيرفر **و** في
`Instances\test\mods` حق اللاعب. لو اختلفوا، اللاعب ينطرد أول ما يدخل.

### الخطوات

1. شغّل الإعداد بنسخة Mohist بدل Paper:
   ```powershell
   .\setup.bat mohist
   ```

2. انسخ مودات سيرفرك من إنستنس CurseForge للسيرفر:
   ```powershell
   xcopy /E /I "C:\Users\wpn\curseforge\minecraft\Instances\test\mods" ".\run\mods"
   ```

3. شغّل السيرفر مرة، وخله يوقف، عشان تتولد إعدادات المودات.

4. ادخل من **إنستنس CurseForge نفسه** (مو من ماين كرافت العادي) على `localhost`.

### ملاحظة صريحة

Mohist/Magma **هجين** — يشغّل بلق إنات ومودات مع بعض، وهذا بطبيعته أقل استقراراً من
سيرفر بلق إنات نقي. لو طلع خطأ في الطريقة (ب) وما طلع في (أ)، **المشكلة في التوافق
الهجين مو في نظام الوظائف** — وهذي معلومة مفيدة بحد ذاتها.

## أخطاء شائعة

| العَرَض | السبب |
|---|---|
| `UnsupportedClassVersionError` | نسخة Java غلط — لازم **8** |
| `.\setup.bat` يقول ما لقى الجار | حمّل الجار من Actions وحطه في `server\acrp-jobs\target\` |
| اللاعب ينطرد أول ما يدخل | مودات اللاعب ≠ مودات السيرفر (الطريقة ب فقط) |
| السيرفر يشتغل بس ما ألقى الأوامر | ما كتبت `op اسمك` في الكونسول |
| ما ألقى المشرفين في الشارع | اكتب `/jobsadmin test training` — بيقول لك مين مو موجود ووش الحل |

## اللي ما أقدر أسويه

ما أقدر أحط ملفات في جهازك مباشرة — أنا أشتغل على سيرفر بعيد وما عندي وصول لـ
`C:\Users\wpn\`. كل اللي فوق لازم تسويه أنت على جهازك، بس ما ياخذ أكثر من دقايق.
