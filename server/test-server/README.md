# سيرفر تجربة ACRPJobs

سيرفر جاهز تجرب عليه كل شي **قبل** ما تنزّله على سيرفرك الحقيقي.
عالم مسطّح، كرييتف، بدون وحوش — وكل المناطق والمسارات والنقاط **محدّدة مسبقاً** حول
نقطة البداية `(0, 4, 0)`، فما تحتاج تحدد ولا نقطة بيدك.

---

## التشغيل

**لينكس / ماك**
```bash
cd server/test-server
./setup.sh              # Paper 1.12.2 (أسرع - يكفي لتجربة البلق إن)
./setup.sh --mohist     # Mohist 1.12.2 (لو تبي تجرب مع مودات سيرفرك)
./run/start.sh
```

**ويندوز**
```
cd server\test-server
setup.bat
run\start.bat
```

بعدها ادخل ماين كرافت **1.12.2** ➜ Multiplayer ➜ `localhost`

> **مهم:** لازم **Java 8** بالذات. ماين كرافت 1.12.2 ما يشتغل على Java 17 أو 21.
> حمّلها من [Adoptium Temurin 8](https://adoptium.net/temurin/releases/?version=8).

أول ما يشتغل السيرفر، اكتب في الكونسول:
```
op اسمك_في_ماين_كرافت
```

## خريطة السيرفر التجريبي

كل شي حول نقطة البداية. اطير (كرييتف) وشوف:

```
                      truck_stops (z=46)
                          ▲
        build_depot ──── truck_depot ──── power_depot
         (-40,24)          (0,24)           (40,24)
             │                │                │
        taxi_stand ───── ★ البداية ───── delivery_depot
         (-24,0)           (0,0)            (24,0)
             │                │                │
       garden_depot ──── cleaner_depot ──── city_dump
        (-40,-24)          (0,-24)          (40,-24)
```

| ماذا | كم |
|---|---|
| مناطق جاهزة | **٢٠** (كل مقرات الوظائف السبع + مجموعات العملاء والمحطات والمواقع) |
| مسارات | **٨** — واحد لكل مشرف جنب مقره + مسار مواطنين حول البداية |
| نقاط عمل | **٨٠** — ٢٠ زبالة · ٢٠ وساخة · ٢٠ زرع · ٢٠ إنارة |

**تأكيد سريع:** اكتب `/jobsadmin zone check` — لازم يقول لك **كل شي موجود**.

> ⚠️ **`respawnMinutes` هنا قصير عمداً (٢-٣ دقائق)** عشان تشوف الدوران بعينك بدون انتظار.
> الافتراضي الحقيقي ١٠ دقائق. لما تجرب، غيّره:
> `/jobsadmin spot set city_trash respawnMinutes 10`

## أسرع طريقة: خلّ النظام يفحص نفسه

قبل ما تمشي الخطوات اليدوية، اكتب:

```
/jobsadmin test
```

يفحص كل شي يقدر يُفحص آلياً ويعطيك تقرير ✔/✘ — المناطق، النقاط، المسارات، المشرفين،
الوظائف وخطواتها، والاقتصاد. **لازم يطلع كله أخضر** قبل ما تكمّل.

وثلاثة أوامر تختصر عليك التجربة اليدوية:

```
/jobsadmin test kit          ← العصي والمضخة دفعة وحدة
/jobsadmin test tp <منطقة>   ← انتقل لأي مقر بدون ما تطير
/jobsadmin test rotate all   ← رجّع النقاط المنظّفة فوراً بدل ما تنتظر
```

> `test rotate all` هو أهم اختصار: نظّف كم كيس ➜ اكتب الأمر ➜ شوفهم يرجعون في أماكن
> ثانية **فوراً** بدل ما تنتظر دقيقتين.

## خطوات التجربة — بالترتيب

### ١. الأساس

```
/jobsadmin zone check          ← لازم: كل المناطق والنقاط موجودة
/jobs                          ← تشوف سبع وظائف
/ac                            ← رصيدك الابتدائي
```

### ٢. التدريب الميداني (المدني الماشي)

```
/jobs join cleaner
```
لازم تجيك: **«روح دوّر على أبو ماجد»**

- روح لـ `cleaner_depot` عند **(0, 4, -24)**
- لازم تشوف قروي اسمه **أبو ماجد** يمشي جيئة وذهاباً
- **نقرة يمين عليه** ➜ يوقف، يلتفت لك، ويعطيك الدرس الأول

✅ **تحقق:** الدرس ما يعدّي إلا لما تسوي اللي قاله فعلاً
- اكتب `/duty` ➜ لازم يجيك **الدرس الثاني** فوراً بصوته
- افتح `/jobs` واختر جولة ➜ **الدرس الثالث**
- نظّف أول كيس ➜ **الدرس الرابع**
- خلّص الجولة ➜ **الدرس الخامس**، وبعده «خلصت التدريب»

✅ **تحقق:** `/jobs learn` يعيد لك الدرس الحالي في أي وقت

### ٣. الزبالة والمضخة

- لازم تجيك **مضخة الماء** في حقيبتك أول ما تسجّل `/duty`
- **كيس الزبالة**: اقترب واضغط **يمين** عليه
- **البقعة الرمادية**: وجّه المضخة عليها واضغط **يمين**، وخلك ثابت ٣ ثواني

✅ **تحقق مهم — الدوران:**
1. `/jobsadmin spot list` ➜ شوف النشط (لازم ٩)
2. نظّف واحد ➜ صاروا ٨
3. `/jobsadmin test rotate city_trash` ➜ يرجع ٩ **بس في مكان ثاني** (أو انتظر دقيقتين)
4. **الأكياس اللي ما نظّفتها ما تحركت** ← هذي أهم نقطة

✅ **تحقق — الحماية:**
- اطلع من الدوام `/duty` ➜ جرّب تنظّف ➜ لازم يرفض
- جرّب ترمي المضخة (`Q`) ➜ لازم يرفض

### ٤. المسارات والمشرفين

```
/jobsadmin route list          ← ٨ مسارات، وكم بوت نشط الآن
```

✅ **تحقق:** ابتعد ٦٠ بلوك عن مشرف ➜ يختفي · ارجع ➜ يظهر **من نفس مكانه**، مو من البداية

✅ **تحقق — السقف:** مجموع البوتات ١٠، والسقف ٥. `route list` لازم يبيّن إن النشطين ٥ فقط،
وإنهم **الأقرب لك**. والمشرفين لهم أولوية على المواطنين المجهولين.

### ٥. باقي الوظائف

| الوظيفة | وين مقرها | المشرف |
|---|---|---|
| `gardener` | (-40, 4, -24) | أم نورة |
| `electrician` | (40, 4, 24) | المهندس سالم |
| `builder` | (-40, 4, 24) | أبو تركي |
| `delivery` | (24, 4, 0) | أبو ريان |
| `taxi` | (-24, 4, 0) | أبو بدر |
| `trucker` | (0, 4, 24) | أبو مشعل |

### ٦. عدم التخريب

✅ خذ عصا التحديد: `/jobsadmin spot wand`
✅ وأنت **في وضع الكرييتف**، اضغط **يسار** على أي بلوك
✅ **لازم ما ينكسر** — بس يتراجع عن آخر نقطة

✅ تأكد إن ما فيه ولا بلوك تغيّر في الخريطة بعد كل التجارب

### ٧. اختبار إعادة التشغيل

```
stop          ← في الكونسول
./run/start.sh
```

✅ **تحقق:**
- الكونسول يقول `Removed N route NPC(s)` و `Removed N work spot item(s)` — تنظيف البقايا
- ما فيه ولا قروي أو كيس تايه في الخريطة
- ادخل ➜ تقدّمك في التدريب **محفوظ من نفس الدرس**
- رصيدك ووظيفتك ورتبتك محفوظة

## لو صار خطأ

| العَرَض | السبب غالباً |
|---|---|
| السيرفر ما يشتغل ويطلع `UnsupportedClassVersionError` | نسخة Java غلط — لازم **Java 8** |
| ما ألقى المشرفين | تأكد `/jobsadmin route list` يبيّن ٨ مسارات، وإنك قريب من المقر |
| ما فيه زبالة | `/jobsadmin spot list` — تأكد `city_trash` عندها ٢٠ نقطة و٩ نشطة |
| `/duty` يرفض | لازم تكون **داخل** منطقة مقر وظيفتك |
| رسائل ناقصة في الشات | احذف `run/plugins/ACRPJobs/messages_ar.yml` وأعد التشغيل |

**أي خطأ في الكونسول** — انسخه كامل من `run/logs/latest.log` وأرسله لي.
